P9 의존성 취약점 감사 증적
============================

실행일: 2026-07-24 (KST)
도구: pip-audit 2.10.1

1. 애플리케이션 요구사항 및 전이 의존성

명령:
  python -X utf8 -m pip_audit -r requirements.txt

결과:
  No known vulnerabilities found

2. 전체 로컬 가상환경

최초 실행 결과:
  pip 25.2에서 알려진 취약점 6건 탐지
  (PYSEC-2026-196, PYSEC-2026-1795, PYSEC-2026-1796,
   PYSEC-2026-196, PYSEC-2026-2875, PYSEC-2026-2876)

조치:
  pip 25.2 -> pip 26.1.2 업그레이드

재실행 명령:
  python -X utf8 -m pip_audit --local

재실행 결과:
  No known vulnerabilities found

비고:
  Windows 한글 경로의 콘솔 디코딩 문제를 피하기 위해 PYTHONUTF8=1과
  Python의 -X utf8 옵션을 사용했다. pip-audit는 감사 도구이므로
  애플리케이션 운영 의존성 requirements.txt에는 포함하지 않는다.
